# Shalfa Operations Enterprise V18

نظام إدارة المدارس والبوابين والمنسقين / المشرفين والحضور والمخالفات والمستندات والخرائط والتقارير.

## تشغيل محلي
```bash
python -m venv .venv
.venv/Scripts/activate   # Windows
pip install -r requirements.txt
uvicorn main:app --reload
```

عند عدم تعريف `DATABASE_URL` يعمل النظام على SQLite محليًا. عند تعريف رابط PostgreSQL يستخدمه تلقائيًا.

راجع: `docs/README_AR.md`.

## تنظيف المشروع

تم تنظيف الحزمة وحذف:
- ملفات README القديمة والمكررة.
- خرائط HTML الثابتة القديمة؛ الخريطة الحالية تعتمد على واجهة النظام.
- ملفات Excel المدمجة القديمة والنسخ التصديرية غير المستخدمة.
- اختبار `smoke_test.py` القديم؛ الاختبارات المعتمدة داخل `tests/`.
- الملفات التعريفية الفارغة داخل `static` و`templates`.

يمكن مراجعة قائمة الحذف في `docs/CLEANUP_MANIFEST.json`.
