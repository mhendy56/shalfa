# إصلاح فلتر المدارس الرئيسية — V18.1

تم تعديل منطق الحضور والتقارير والتصدير بحيث:

- اختيار **الرئيسية فقط** يعرض السجلات التي قيمتها الموحّدة `رئيسية` فقط.
- الحقول الفارغة أو غير المحددة لا تُعامل تلقائيًا كمدارس رئيسية.
- توحيد القيم عند استيراد Master Data:
  - رئيسية / رئيسي / أساسية / أساسي ← رئيسية
  - فرعية / فرع ← فرعية
  - ملحقة / ملحق ← ملحقة
  - القيمة التي لا يمكن تحديدها ← غير محدد
- تم توحيد البيانات الموجودة تلقائيًا عند تشغيل النسخة.
- تم تطبيق نفس المنطق على شاشة الحضور، تصدير Excel، API الحضور، وتقارير الفترة.
