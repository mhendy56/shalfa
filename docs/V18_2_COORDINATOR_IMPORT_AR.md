# Shalfa Ops V18.2 — استيراد المنسقين / المشرفين

تمت إضافة الاستيراد داخل شاشة **إدارة المنسقين / المشرفين**.

## الوظائف

- تحميل قالب Excel.
- استيراد وتحديث المنسقين بالرقم الوظيفي.
- المطابقة بالاسم عند عدم وجود رقم وظيفي.
- إضافة المنسق الجديد ومنع التكرار.
- تحديث: الاسم، الجوال، البريد، المدينة، القطاع، الحالة والملاحظات.
- ربط المدارس بالمنسق عند وجود الرقم الوزاري في الملف.
- تسجيل كل تغيير في سجل إسناد المنسقين.
- خيار اختياري لإيقاف المنسقين غير الموجودين في الملف بدل حذفهم.
- تصدير المنسقين الحاليين وتوزيع المدارس.
- عرض ملخص نتيجة الاستيراد داخل الشاشة.

## أعمدة القالب

الرقم الوظيفي، اسم المنسق / المشرف، الجوال، البريد الإلكتروني، المدينة، القطاع، الحالة، الرقم الوزاري، ملاحظات.

يمكن تكرار نفس المنسق في عدة صفوف، صف لكل مدرسة تابعة له.
