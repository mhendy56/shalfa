# Shalfa Ops V18.3 — Project Command Center

تم تطوير غرفة العمليات إلى مركز قيادة حي للمشروع بدون شاشة فيديو.

## المكونات
- مؤشر صحة المشروع من 100.
- خريطة حية للمدارس وتلوين المخاطر.
- حضور وغياب وعدم تسجيل لحظيًا.
- تنبيهات مرتبة حسب الخطورة مع خيار «تمت المعالجة».
- أداء المنسقين / المشرفين.
- البلاغات والحوادث والجولات والتصاريح والمخالفات والعجز.
- المستندات الناقصة والمنتهية خلال 30 يومًا.
- جودة البيانات: مدارس بدون بواب أو منسق أو إحداثيات، وبوابون غير مرتبطين.
- Live Feed وشريط أخبار مباشر.
- وضع طوارئ يركز على الحالات الحرجة والخريطة.
- تحديث تلقائي كل 30 ثانية وصوت اختياري للتنبيهات الحرجة.
- ملء الشاشة والطباعة إلى PDF وتصدير Excel.

## الصفحة الافتراضية
بعد دخول المدير أو مدير المشروع أو المشرف، يتم فتح مركز القيادة مباشرة.
