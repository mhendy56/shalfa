# V22 — موظفو الصيانة والنظافة وحصر وتسعير الأصول

- شاشة موظفين مع إضافة يدوية واستيراد Excel وخيار استبدال القديم.
- حصر الأصول يدويًا أو من عدة ملفات Excel في عملية واحدة.
- تسجيل الكمية والحالة والموقع والقائم بالحصر ومصدر الملف.
- رفع صورة الأصل من الجوال أثناء الحصر أو بعده.
- قائمة أسعار قابلة للاستيراد مع نوع الأصل والموديل والحالة ومعامل الحالة.
- تسعير الأصل تلقائيًا بمجرد الحصر أو بعد تحديث قائمة الأسعار.
- سجل تاريخي لتغير سعر الأصل.
- تقرير Excel موحد للموظفين والحصر والتسعير.
